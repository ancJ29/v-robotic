Page prose for the pages that have no content type behind them (services, AI technology, partnership, about, contact).
One module per page, one typed object per module, shaped like a Strapi single type so a later piece can lift it:
each key is a field, each list is a repeatable component. Templates read these objects and own the layout only.
Text was read off the client's reference screens; anything provisional is marked in the module.
Interface labels shared across pages (buttons, kickers, breadcrumbs) live in `../i18n/vi.json`, not here.
